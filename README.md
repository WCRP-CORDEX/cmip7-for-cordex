# CMIP7 for CORDEX

This repo is intended collect information on CMIP7 output available for CORDEX. For the moment, it is just collecting discussions as issues, where we can shape the content that we expect the repo to provide.

A key resource is the Airtable where CMIP collects the [CMIP7 simulations status](https://airtable.com/applbQctZtl09L2Ga/shrg4OSiuBhfeKxvp/tblRtiWb7mDz7D49c), which includes the support for downstream activities, including CORDEX.
