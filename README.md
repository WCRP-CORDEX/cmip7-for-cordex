# CMIP7 for CORDEX

This repository is intended to collect information on CMIP7 output available for CORDEX.
For the moment, it is just collecting discussions as issues, where we can shape the content that we expect the repository to provide.

A key resource is the Airtable where CMIP collects the [CMIP7 simulations status](https://airtable.com/applbQctZtl09L2Ga/shrg4OSiuBhfeKxvp/tblRtiWb7mDz7D49c), which includes the support for downstream activities, including CORDEX.

Apart from the regular search for [CMIP7 data on ESGF-NG](https://metagrid-ceda.east.esgf.io/search?project=CMIP7), this [monitor](https://www.climate-resource.com/tools/esm-model/cmip7-availability) provides a summary of the progress of CMIP7 data publication.
Moreover, the WCRP Rapid Evaluation Framework (REF) is already showing [performance metrics for CMIP7](https://staging.climate-ref.org/explorer/themes?theme=atmosphere&mip_era=CMIP7) data.
